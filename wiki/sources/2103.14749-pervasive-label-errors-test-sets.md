## 概述

本文系统测量了 10 个被广泛用作 benchmark 的计算机视觉 / NLP / 音频测试集中的 label error，并分析这些错误对模型选择的后果。方法上先用 confident learning (CL) 算法筛出疑似错标样本，再用 Mechanical Turk 众包人工核验。结论有两层：一是测试集错标平均至少 3.3%（ImageNet 验证集至少 6%）；二是更关键的——在被纠正的那部分测试数据上，**容量更大的模型反而更差**，模型排名可以发生剧烈翻转，因此按原始 test accuracy 做模型选择可能选错模型。

**论文信息**: NeurIPS 2021 Track on Datasets and Benchmarks（第 35 届）, Curtis G. Northcutt (ChipBrain / MIT / Cleanlab)、Anish Athalye (MIT / Cleanlab)、Jonas Mueller (AWS), 2021, arXiv:2103.14749（v4, 2021-11-07）

## 关键发现

1. **错标是普遍现象，但量级差异极大**：10 个数据集测试集错误率从 MNIST 的 0.15% 到 QuickDraw 的 10.12%，人工验证给出的平均下界为至少 3.3%。ImageNet 验证集（因测试集标签不公开，实际被当作 test set 使用）验证出 2916 个错误，约 6%；QuickDraw 估计超过 500 万个错误（约 10%）。作者指出：数据集越简单、标注方法设计越用心、人工筛查越充分的数据集，错误越少。
2. **删掉错标不改变排名，但在"可纠正子集"上排名剧烈翻转**：仅移除 label error 时 34 个 ImageNet 预训练模型的相对排名基本不变（与 Recht et al. 的观察一致）；但只在 correctable set（人工共识给出了另一个明确标签的子集）上评测时，用原始（错误）标签 vs 用纠正后标签，排名剧变：NASNet-large 从 1/34 掉到 29/34，Xception 从 2/34 掉到 24/34，ResNet-18 从 34/34 升到 1/34，ResNet-50 从 20/24 升到 2/24。CIFAR-10 上用 13 个预训练模型独立复现了同一趋势（VGG-11 在纠正后精度上显著优于 VGG-19）。
3. **只要噪声比例小幅上升，模型选择就会选错**：在 ImageNet 上，若原始错标样本的比例相对 pruned set 的初始值（N = 2.9%）再上升约 6 个百分点（即 N = 9%），ResNet-18 的纠正后精度就超过 ResNet-50；CIFAR-10 上比例上升约 5 个百分点时 VGG-11 超过 VGG-19。
4. **作者明确否认这是传统过拟合**：所有数字都是在 held-out 测试数据的子集上算的。他们给出两点解释假设：(1) 低容量模型对非对称噪声有意外的正则化 / 抗拟合作用；(2) 近年更大模型的架构 / 超参决策本身是基于（含错标的）原始 test accuracy 做出的，属于对特定 benchmark 及其标注者癖好的过拟合。
5. **CL 筛选 + 众包核验的组合被专家复核验证有效**：CL 标记的样本被判定为错标的可能性是未被标记样本的 2.6 倍，因此 CL 适合作为大规模人工复核的优先级排序器；CL 过滤常可把需要人工验证的样本量减少约 90%。
6. **真实错误率被低估**：由于只核验了 CL 标记的子集，作者据专家复核推算 ImageNet 验证集实际错标接近 20%（而非表 1 报告的 6%）——89% 的图像未被 CL 标记，其中约 16% 也是错标，折算约多出 14%。

## 方法

**错误定位（CL）**：对含 $n$ 个样本、$m$ 个类的测试集，用 confident learning 估计观测噪声标签 $\tilde{y}$ 与未知真标签 $y^*$ 的 $m \times m$ 联合分布 $Q_{\tilde{y},y^*}$。核心前提是 **class-conditional noise**：错标概率只依赖潜在真类，不依赖样本本身（例：ImageNet 里 tiger 更可能被错标成 cheetah 而非 CD player）。错误比例 $\rho = 1 - \sum_{i \in [m]} \hat{p}(\tilde{y}=i, y^*=i)$，错误个数为 $\rho \cdot n$；按 normalized margin $\hat{p}(\tilde{y}=i;x) - \max_{j \neq i}\hat{p}(\tilde{y}=j;x)$ 排序取前 $\rho \cdot n$ 个作为候选。CL 需要两个输入：out-of-sample 预测概率矩阵 $\hat{P}_{k,i}$（先在训练集预训练、再在测试集上做交叉验证微调以保证 out-of-sample；无显式测试集的数据集如 QuickDraw / Amazon Reviews 则在全量数据上交叉验证）与测试集标签。

**人工核验（MTurk）**：每个 CL 标记样本独立交给 5 名 worker，问其看到的是 (1) 原标签、(2) CL 预测的 top 标签、(3) 两个都有、(4) 两个都没有。**agreement threshold = 3/5**：少于 3 人支持原标签即判为 error，否则判为 non-error。错误进一步分为 correctable（多数同意 CL 预测标签）、multi-label（多数同意两个标签都出现）、neither（多数同意两个都不是）、non-agreement（无多数）。大数据集（QuickDraw、Amazon Reviews）只抽查随机样本，其余全量核验。

**关键定义与实验设计**：original accuracy $\tilde{A}$（按原标签算，即当前通行做法）vs corrected accuracy $A^*$（按纠正后标签算）；benign set $\mathcal{B}$、unknown-label set $\mathcal{U}$、pruned set $\mathcal{P} = \mathcal{D} \setminus \mathcal{U}$、correctable set $\mathcal{C}$；noise prevalence $N = |\mathcal{C}| / |\mathcal{P}|$。为模拟不同噪声水平，从 $\mathcal{B}$ 中随机移除比例 $x$ 的正确标注样本，则 $N = \frac{|\mathcal{C}|}{|\mathcal{P}| - x|\mathcal{B}|}$，模型期望精度按 $A(x;\mathcal{M}) = \frac{A_{\mathcal{C}}(\mathcal{M})\cdot|\mathcal{C}| + (1-x)\cdot A_{\mathcal{B}}(\mathcal{M})\cdot|\mathcal{B}|}{|\mathcal{C}| + (1-x)\cdot|\mathcal{B}|}$ 线性插值，从而可模拟 $N$ 从 $|\mathcal{C}|/|\mathcal{P}|$ 到 1 的任意值。$\mathcal{U}$ 在噪声率估计与精度计算中都被忽略（因为真标签本身歧义）。

**专家复核（第 6 节）**：两阶段。第一阶段对 ImageNet 1000 个类各取 1 个 CL 标记样本和 1 个非 CL 标记样本（66 个类无 CL 标记样本，故 934 + 1000 = 1934 张），界面与 MTurk 类似；专家会上网查资料，平均每张耗时是 MTurk worker 的 13 倍。每张至少 2 名专家复核，77% 的图像专家意见一致；第二阶段对剩余 23% 争议图像共同讨论达成共识。

## 局限与假设

- **class-conditional noise 假设**：CL 的噪声刻画假定错标只依赖真类而非具体样本。论文称该假设在实践中常见且合理，但这是量化结果的前提。
- **只核验 CL 标记的子集**，因此所有错误率都是**下界**；论文明确说本文分析对问题严重性给出的是 loose lower bound，真实的 correctable set 更大，噪声率估计偏向有利于大容量模型。
- **纠正后的标签本身不是 100% 正确**：即使 5/5 一致，"corrected" 标签也可能是错的（论文 Figure 2 给出 CL 的失效模式：局部裁剪的缝纫机、从驾驶舱视角拍的飞机、画得很差的"5"、年龄不明的男性面孔、微缩村庄模型里当柱子用的吸管等）；作者只声称纠正后测试集比原始测试集"有改进"。
- **unknown-label set $\mathcal{U}$ 被整体排除**：多标签或都不符合的样本无法定义"更好的精度"，故不进入噪声率与纠正后精度的计算，因此本文的 noise prevalence 与"测试集中实际的错标比例"不是同一个量。
- **未能区分大模型表现下降的成因**：论文明确说未回答这是训练集噪声过拟合、超参调优阶段对验证集噪声过拟合，还是标签纠正带来的 train/test 标签分布漂移；也未回答给定人工标注预算应如何在训练集与测试集之间分配。
- **模拟噪声上升的方式是随机移除干净样本**，属于对"更脏的真实数据集"的近似，并假定被移除后的测试集仍能代表相应噪声水平下的应用场景。
- **数据集工程层面的杂音**：ImageNet 存在重复类标签（maillot 638/639、crane 134/517），Caltech-256 存在重复图像，IMDB / QuickDraw / Caltech-256 缺少全局索引，作者为此自行提供索引文件。
