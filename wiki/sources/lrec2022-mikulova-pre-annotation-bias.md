## 概述

本文用一个精心平衡的对照实验，检验**自动预标注（pre-annotation）是否会损害人工标注质量**——即标注者是否会「懒得改、直接顺着模型输出走」。任务是中等复杂度的捷克语依存句法标注（PDT-C 项目），对比「在高精度 parser 预标注结果上修改（pre-parsed）」与「完全从零手工标注（from-scratch）」，同时交叉考察另外两种辅助工具（自动检查规则、同一数据上的语义层标注）的影响。结论是：预标注**提速明显、一致性上升，而对照金标准的准确率没有下降**，因此作者强烈推荐在句法标注项目中使用自动预标注。

**论文信息**: LREC 2022（第 13 届语言资源与评测会议）, 2022, ACL Anthology 2022.lrec-1.312；arXiv:2306.09307v1。作者 Marie Mikulová, Milan Straka, Jan Štěpánek, Barbora Štěpánková, Jan Hajič（布拉格查理大学 ÚFAL）

## 关键发现

1. **准确率没有因预标注而下降**。以 no_supp（无任何辅助工具）任务为例：UAS 预标注 96.5 vs 从零 96.5；LAS 95.0 vs 94.5；FULL 94.5 vs 94.3。作者结论是两种模式下准确率「大体相同」，波动量级约等于标注者间的标准差（约 0.5 个百分点）。在四个任务、三项指标共 12 组对比中，两种模式的差异都在这一波动范围内，方向不一致（部分组 pre-parsed 略高，rul_annot 任务中 from-scratch 略高）。
2. **人工修正显著超过 parser 自身水平**。在本实验数据上 parser 的准确率为 UAS 90.0 / LAS 86.8 / FULL 86.5（低于其在 PDT 测试集上的 94.18/91.37，因为换了领域并改动了部分标注规则）；经过人工修正后升至 96.5 / 94.9 / 94.5。也就是说标注者**确实做了大量实质性修改**，并非照抄。
3. **速度提升约 1.7 倍**。从零标注平均耗时约为预标注模式的 1.7 倍。按任务平均（分钟/1250 词数据集）：no_supp 预标注 118 vs 从零 200；rules 129 vs 185；annot 151 vs 186；rul_annot 128 vs 178。
4. **一致性（IAA）在预标注下更高，但作者明确指出这正是偏倚的表现**。no_supp 任务：unlabeled $\kappa$ 0.96（预标注）vs 0.95（从零）；labeled $\kappa$ 0.99 vs 0.96；full-labeled $\kappa$ 0.98 vs 0.96。作者的解释是「预标注提升一致性可归因于**标注者的判断受到了自动预标注输出的影响**；但如前所述，预标注并不影响结果的质量」。即偏倚存在（标注结果被拉向同一个 parser 输出），只是没有表现为对金标准的准确率损失。
5. **其他辅助工具单独用效果不如预期，组合使用才显著**。仅提供自动检查规则（rules）的效果很弱，与作者此前经验（Mikulová & Štěpánek 2010）相矛盾，作者归因于当时只有 9 组检查规则可用。而「检查规则 + 可对照的语义层标注」组合（rul_annot）相对 no_supp 在 UAS/LAS/FULL 上都显著更优（如 from-scratch 模式下 LAS/FULL 的 $p<0.1\%$）。
6. **成本外推**：对 PDT-C 约 200 万 token 的语料，单遍主标注可节省约 2000 小时（5400 → 3400 小时），约合 1.3 人年、至少约 21,000 美元；由于实际采用双人标注，时间与成本节省再翻一倍。

## 方法

- **任务**：PDT-C（Prague Dependency Treebank - Consolidated）的依存句法层标注——为每个节点确定 head 并赋 afun（句法功能）标签。基本 afun 25 类，叠加 `_E`/`_P`/`_Co`/`_Ap` 等词缀后理论上可达 200 类。实验数据取自 PDT-C 的 PCEDT 部分（华尔街日报的捷克语译文）。
- **设计（4 任务 × 2 模式 = 8 种配置）**：任务为 no_supp（无辅助）、rules（自动「在线」检查规则）、annot（可查看同一数据的语义层标注）、rul_annot（两者兼有）；模式为 pre-parsed（在 parser 输出上修改）与 from-scratch（从零）。
- **数据规模**：8 个数据集 D1–D8，各 1250 词（约 60 句），每任务 2 个数据集共 2500 词。数据集在句数、节点数、树深等方面尽量相近，以消除数据效应。
- **标注者**：4 名标注者（a1–a4）组成固定配对，配对方式经过平衡设计——**每一对都经历全部 8 种配置，且任何标注者不重复标注同一份数据**，以消除学习效应并平摊标注者个人风格。
- **预标注模型**：UDPipe 2 + RobeCzech（捷克语 RoBERTa），在 PDT-C 1.0 训练集上训练（含 afun 词缀），PDT etest 上 UAS 94.18 / LAS 91.37；在 PCEDT 的 2000 句上 UAS 93.25 / LAS 90.93。标注工具为 TrEd。
- **金标准构建**：每个数据集共被标注 4 次（from-scratch 2 次、pre-parsed 2 次），做 diff 后由规范制定者裁决分歧，形成 gold standard。
- **指标**：UAS（仅 head）、LAS（head + 25 类基础 afun，忽略词缀）、FULL（head + 含词缀的完整 afun）；Cohen's $\kappa$ 用 $\kappa = 1 - \frac{1-p_0}{1-p_e}$，其中 unlabeled 用 $p_0 = a_P/n$、$p_e = \bar{s}^{-1}$（$\bar s$ 为平均句长）；labeled 用 $p_0 = a_L/a_P$、$p_e = 1/25$；full-labeled 用 $p_e = 1/200$。准确率的标准差由 100 万次 bootstrap 重采样估计，$p$ 值由 100 万样本的 Monte Carlo 置换检验给出。
- **关键假设与口径**：Table 2 中的 $p$ 值检验的是**「该配置是否显著优于同模式下的 no_supp 配置」**，而**不是** pre-parsed 与 from-scratch 之间的对比。因此「预标注不损害质量」是基于差异落在噪声范围内的判断，论文并未报告针对预标注这一对比的显著性检验。

## 局限与假设

- **样本极小**：每个任务仅 2500 词、约 120 句，仅 4 名标注者。准确率差异的 bootstrap 标准差约 0.5 个百分点，与两模式间的观测差同量级，因此本实验**只能支持「没检测到质量下降」，不能支持「一定没有下降」**（缺乏效力分析）。
- **未对预标注这一对比做显著性检验**：Table 2 的 $p$ 值全部是相对 no_supp 的工具效应检验，不是 pre-parsed vs from-scratch 的检验。
- **金标准由同一批标注结果构建**：gold 来自 4 次标注（其中 2 次是 pre-parsed 模式）的 diff + 规范制定者裁决。若预标注造成的是**系统性、被多位标注者共同接受的**偏倚，这种金标准构建方式原则上难以将其识别为错误；论文未讨论这一循环性。
- **一致性提升与偏倚同源**：作者本人把预标注模式下更高的 $\kappa$ 解释为标注者判断受 parser 输出影响的结果。因此不能把「一致性上升」当作纯粹的质量改善——它同时是偏倚存在的证据。
- **速度数据难以归因**：标注者之间速度差异极大（预标注 50–200 分钟/任务，从零 130–280 分钟/任务），作者明确表示因个体差异过大，难以就辅助工具与速度的关系下结论。
- **任务与语言特定**：仅覆盖捷克语依存句法这一「中等复杂度」任务，且 parser 精度很高（UAS 90+）。预标注质量较低时结论未必成立。
- **仅适用于经过训练的专业标注者**：标注者为项目内熟悉规范者，结论不能直接外推到众包。

## 对二阶段标注/复核设计的含义

- 该文常被用作「预标注不损害质量」一侧的证据，方向上确实如此：**质量持平、速度约 1.7 倍、一致性上升**。
- 但真正可迁移的读法更谨慎：预标注**确实改变了标注者的判断分布**（一致性上升即其表现），只是这种改变在「由同一批标注构建的金标准」下未表现为准确率损失。要检验「模型预标注造成的系统性偏倚」，需要独立于该批标注的金标准。
- 值得注意的对比：**在这套设置中提升质量的是「检查规则 + 交叉参照的另一层标注」的组合，而不是预标注本身**；预标注的收益主要在效率。
