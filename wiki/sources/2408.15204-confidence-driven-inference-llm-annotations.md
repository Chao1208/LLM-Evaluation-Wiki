## 概述

本文提出 **CONFIDENCE-DRIVEN INFERENCE**：把 LLM 标注与 LLM 自报的 **verbalized confidence（语言化置信度）** 结合起来，据此**策略性地决定该把有限的人工标注预算花在哪些样本上**，再把人工标注与 LLM 标注融合成一个**无偏估计量**与**统计有效的置信区间**。方法建立在 active inference（Zrnic & Candès, 2024）之上，是 prediction-powered inference (PPI) 的自适应精化版本。核心卖点是"有安全网"：无论 LLM 标注质量多差、置信度多不准，结论**都不会比只用人工标注更差**。作者来自 Stanford（含 Emmanuel Candès、Dan Jurafsky）。

**论文信息**: arXiv preprint（v2, 2025-02-08）, 2024, arXiv:2408.15204

## 关键发现

1. **把 LLM 标注当人工标注直接用（LLM only）会得出错误结论**，即使总体一致率看起来不低。stance 任务上 LLM 与人工的 Cohen's $\kappa_{\mathrm{stance}} = 0.57$（三个设定中最高），但仅用 LLM 标注估 odds ratio 时**方向都错了**（估出 $O_{\mathrm{agreement}} > 1$，真值 $< 1$），coverage 为 0%。五个任务中 LLM only 的 coverage 只有 52%、69%、0%、2%、90%，远低于 90% 目标。

2. **verbalized confidence 在三个设定中都与准确率正相关（校准良好）**，这是方法能用的实证前提：置信度高的样本，其 LLM 标注与人工标注更一致，因此可以把稀缺的人工标注集中投给低置信度样本。置信度用 Tian et al. (2023) 的两阶段 prompting 获得（先零样本作答，再让模型给这个答案一个正确概率 $C_i \in [0,1]$）。

3. **置信度信号驱动的是"采样概率"，不是"最终答案"**。理论最优采样概率 $\pi_i^* \propto \sqrt{\mathbb{E}[(\hat{H}_i - H_i)^2 | T_i]}$，即按"LLM 标注误差的量级"采样；由于真标签未知，作者用 $\{(C_j, (\hat{H}_j - H_j)^2)\}$ 训一个黑箱预测器 $\widehat{\mathrm{err}}_i(C_i)$，然后设 $\pi_i \propto \sqrt{\widehat{\mathrm{err}}_i(C_i)}$，归一化使 $\sum_i \pi_i = n_{\mathrm{human}}$。

4. **无偏性来自"已知采样概率 $\pi_i$"的逆概率加权**，与 active testing 的重要性加权同源。这也是为什么 $\hat\theta^{\mathrm{conf}}$ 在大样本极限下期望**恰好**等于 $\theta^*$，**无论 LLM 标注偏差多大**。

5. **power tuning 提供"永不变差"的保证**。参数 $\lambda \in [0,1]$ 在"完全忽略 LLM 标注"（$\lambda = 0$，等价于经典 human-only 估计）与"完全信任"（$\lambda = 1$）之间插值，取值使 MSE 最小。因此错误的 LLM 标注或失准的置信度**不会伤害**估计——最差也就退化到 $\lambda = 0$。

6. **非自适应的 human + LLM 基线（即均匀采样版 PPI，Egami et al. 2024）有时会倒扣**：在两个 politeness 任务上其 effective sample size 增益为**负**（$-16.76\%$、$-8.05\%$），也就是引入 LLM 标注反而让估计更差；而 confidence-driven 在全部五个任务上都为正增益。

7. **在同等精度下人工标注需求至少减少 25%**（全部任务），部分任务减少幅度大得多。

## 方法

**设定**：语料 $T_1,\dots,T_n$ i.i.d.，目标量 $\theta^*$ 通过 M-estimator 定义

$$\hat\theta = \arg\min_\theta \frac{1}{n}\sum_{i=1}^n \ell_\theta(X_i, H_i)$$

其中 $H_i$ 是人工标注，$X_i$ 是无需人工标注即可获得的协变量（如语言标记的词典命中）。均值、logistic / linear 回归系数、分位数、prevalence 都是特例。约束是只能采集 $n_{\mathrm{human}} \ll n$ 个人工标注（平均意义），LLM 标注 $\hat H_i$ 对全部 $n$ 个样本可得，且**不假设其质量好**。

**估计量**：令 $\xi_i = \mathbb{1}\{H_i \text{ 被采集}\}$，$\Pr(\xi_i = 1) = \pi_i$，

$$\hat\theta^{\mathrm{conf}} = \arg\min_\theta \frac{1}{n}\sum_{i=1}^n \left(\lambda \hat\ell_{\theta,i} + (\ell_{\theta,i} - \lambda\hat\ell_{\theta,i})\frac{\xi_i}{\pi_i}\right)$$

其中 $\ell_{\theta,i} = \ell_\theta(X_i, H_i)$、$\hat\ell_{\theta,i} = \ell_\theta(X_i, \hat H_i)$。每个求和项对 $\xi_i$ 取期望后恰等于 $\ell_{\theta,i}$，故该损失平均等于"理想损失"。以估计均值为例可化简为

$$\hat\theta^{\mathrm{conf}} = \frac{1}{n}\sum_{i=1}^n\left(\lambda\hat H_i + (H_i - \lambda\hat H_i)\frac{\xi_i}{\pi_i}\right), \quad \mathbb{E}[\hat\theta^{\mathrm{conf}}] = \mathbb{E}[H_i] = \theta^*$$

**置信区间**：$C_{1-\alpha} = (\hat\theta^{\mathrm{conf}} \pm z_{1-\alpha/2}\hat\sigma_{\mathrm{se}})$，标准误有闭式表达（附录 A.1），有效性由 Zrnic & Candès (2024) 的理论保证。

**与 PPI 的关系**：PPI（Angelopoulos et al., 2023a）用模型预测提升推断效率但**均匀**抽取需人工标注的样本；active inference 用**自适应**数据采集精化 PPI；本文的贡献是把"自适应采样规则"接到 **LLM 的语言化置信度**上，并配合 power tuning（PPI++，Angelopoulos et al., 2023b）。$\widehat{\mathrm{err}}$ 不每步重拟合，而是每 50 或 100 个数据点周期性更新。

**评价指标**：
- *effective sample size* $n_{\mathrm{effective}}$：使 human-only 方法达到同等 MSE 所需的人工标注数；增益定义为 $(n_{\mathrm{effective}} - n_{\mathrm{human}})/n_{\mathrm{human}} \times 100\%$。
- *coverage*：置信区间覆盖 $\theta^*$ 的比率（目标 90%；因 $\theta^*$ 未知，用全量数据上的式(1)估计作代理）。

## 重要数据

三个 CSS 设定、五个目标量，主实验用 GPT-4o 零样本标注（GPT-3.5 结果见附录 B.1），$n_{\mathrm{human}} = 500$，100 次试验：

| 估计任务 | 目标量 | confidence-driven 增益 | human+LLM（非自适应）增益 | LLM only coverage |
|---------|-------|----------------------|--------------------------|------------------|
| Politeness devices (hedge) | $\beta_{\mathrm{hedge}}$ | **(30.02 ± 7.82)%**，coverage 95% | (−16.76 ± 8.08)%，coverage 89% | 52% |
| Politeness devices (1st person pl.) | $\beta_{\mathrm{1pp}}$ | **(319.44 ± 22.09)%**，coverage 94% | (−8.05 ± 30.09)%，coverage 94% | 69% |
| Stance on global warming | $O_{\mathrm{agreement}}$ | **(102.51 ± 13.01)%**，coverage 96% | (13.72 ± 22.79)%，coverage 96% | 0% |
| Political bias (left-leaning) | $p_{\mathrm{left}}$ | **(29.94 ± 8.19)%**，coverage 97% | (20.56 ± 6.33)%，coverage 94% | 2% |
| Political bias (right-leaning) | $p_{\mathrm{right}}$ | **(63.73 ± 11.48)%**，coverage 91% | (61.15 ± 8.75)%，coverage 95% | 90% |

数据集规模：politeness（Stack Exchange + Wikipedia 请求）$n = 5{,}480$；stance（新闻标题）$n = 2{,}300$；political bias（新闻文本随机抽样）$n = 2{,}000$。

其他数字：
- $n_{\mathrm{human}} = 1000$ 时，confidence-driven 的 effective sample size 至少 1250（最差情形为估 $p_{\mathrm{left}}$）。
- 要达到 $n_{\mathrm{effective}} = 1000$，只需约 250（$\beta_{\mathrm{1pp}}$）到 750（$p_{\mathrm{left}}$）个人工标注；相比非自适应基线，分别少 750（$\beta_{\mathrm{1pp}}$）与 200（$O_{\mathrm{agreement}}$）个人工标注。

代码与数据：github.com/kristinagligoric/confidence-driven-inference。

## 局限与假设

- **两条外部有效性前提**：(a) 文本实例是来自目标分布的 i.i.d. 样本；(b) 研究者**完全掌控标注流程**。分布随时间漂移（如语言习惯演变）或某些标注难以获取（如低资源语言）时都会违反，作者明确警告不要外推到这两条不成立的场景。
- **人工标注被当作 gold standard**，但作者自承人工标注本身有偏、合理的标注者也会分歧；建模标注者层面的变异与偏差留待未来工作。众包标注本身可能已被 LLM 污染（本文用的是 LLM 普及前收集的数据集）。
- **采样概率选得差会增大 MSE**（例如置信度失准），甚至可能超过 human-only 基线的 MSE；这一风险由 power tuning 兜住——保证"把 LLM 标注纳入估计"不会变差，但对采样规则本身的次优性只是缓解而非消除（敏感性分析见附录 B.2）。
- coverage 数字用全量数据估计作 $\theta^*$ 代理，因此**略微上偏**；作者说明报告 coverage 的主要目的是暴露 LLM-only 的问题，其余方法只作 proof of concept。
- 只测了少量 LLM（GPT-4o、GPT-3.5），不构成 benchmark；实验仅限英文 CSS 数据集上的估计任务，不涉及因果效应识别（虽然方法可用于因果估计）。
- 需要 LLM 能给出**可用的**置信度信号。论文因 RLHF 导致的过度自信与 token 概率失准而选用 verbalized confidence，其校准性在本文三个设定中成立，但不保证跨任务成立。
