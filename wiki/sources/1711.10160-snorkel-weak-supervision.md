## 概述

Snorkel 是首个端到端实现 **data programming** 范式的系统：用户不再手工标注数据，而是写 **labeling function（LF，标注函数）**——表达启发式规则、正则模式、外部知识库、弱分类器、众包投票等任意弱监督信号，每个 LF 可以给出标签或**弃权（abstain）**。Snorkel 在**没有任何 ground truth** 的条件下用一个**生成式模型**估计各 LF 的准确率与相关性，把冲突/重叠的噪声标签去噪合成为**概率标签**，再用这些概率标签训练下游判别模型。论文来自 Stanford（Ratner、Bach、Ré 等）。

**论文信息**: PVLDB Vol. 11 No. 3（VLDB 2018）, 2017, arXiv:1711.10160

## 关键发现

1. **未加权多数投票不够用**。论文的 Example 1.1：高准确率低覆盖的 Source 1（90% 准确）与低准确率高覆盖的 Source 2（60% 准确）冲突时，未加权投票会产生大量平票（null）；即使优先用 Source 1、缺失时退回 Source 2，期望训练集准确率也只有 **60.3%**，仅略优于更弱的那个源。必须按估出的真实准确率加权，并把这份 lineage 信息传给下游模型。

2. **生成式标签模型带来的增益取决于 label density $d_\Lambda$**（每个数据点上非弃权标签的平均数），存在三段式规律：低密度时冲突太少，多数投票已近最优（Proposition 1：期望最优优势上界随密度平方衰减，$O(\bar{d}^2)$）；高密度时多数投票指数收敛到最优解（Theorem 1，来自对称 Dawid-Skene 结论）；**中密度区间**才是生成式建模收益最大的地方。

3. **系统会自动决定"要不要训生成模型"**。作者定义 modeling advantage $A_w$（按真实准确率加权投票相对未加权投票的准确率提升），并构造一个只依赖 label matrix $\Lambda$ 的**上界** $\tilde{A}^*(\Lambda)$（Proposition 2）作为廉价指标，若 $\tilde{A}^*(\Lambda) < \gamma$ 就直接用 majority vote。该 optimizer 在所有成熟应用上都选对了策略，平均带来 **2.16 个准确率点**的增益，并把 pipeline 执行加速最多 **1.8×**。

4. **相关性结构必须自动学，手写不现实**。Example 3.1：10 个 LF 中 5 个完全相关（每个点投票一致）、5 个条件独立且准确率 99%，独立模型的最大似然估计会给出 $\hat\alpha = 100\%$、$\hat\beta = 50\%$——完全颠倒。Snorkel 用 pseudolikelihood 的结构学习（Bach et al., 2017）代替最大似然：100 个 LF、10,000 数据点时估所有成对相关只需 **15 秒**（全参数估计约需 45 分钟）。相关性学习保留了 **60%–70%** 的收益，同时节省最多 **61%** 训练时间（单次执行 34 分钟）。

5. **相关性阈值 $\epsilon$ 存在"elbow point"**。选中相关数随 $\epsilon$ 减小先缓慢增长、随后爆炸；取拐点是性能与算力的安全折衷。Spouses 任务上 $\epsilon = 0.08$ 得 56.6 F1，距最佳分数 1 分以内，但参数估计只需 8 分钟。

6. **判别模型能超越 LF 本身，主要通过提高 recall**。关系抽取任务上判别模型相对生成模型平均提升 recall **43.15%**（Example 2.5：CDR 中 33 个 LF 全部弃权的句子，判别模型仍正确识别）。相比"跳过生成模型、直接在未加权 LF 输出上训判别模型"，用 Snorkel 概率标签平均提升 **5.81%**（论文正文另一处表述为生成建模阶段提升 **5.81%**；Table 5 六个任务 lift 分别为 +5.5、+0.5、+3.3、+1.4、+3.1、+5.0）。

7. **相对基线的整体增益**：比 distant supervision 基线平均高 **132%**（两个真实部署中平均高 110%，四个开源数据集上平均高 153%）；相对大规模人工标注训练集的预测性能，平均只差 **3.60%**（关系抽取任务 F1 差 2.11%，跨模态任务准确率/AUC 差 5.08%）。

8. **user study 证实"写 LF 比手工标注更省时"**。15 位生物医学研究者经两天 workshop、2.5 小时开发时间写 LF，与用等量时间（7 小时人工标注、按众包每标签 10 秒折算）训练的模型对比：**8 位（多数）匹配或超过**手工标注模型；Snorkel 用户平均 **30.4 F1** vs 手工标注平均 **20.9 F1**；最好的用户模型 48.7 F1，比最好的手工标注模型高 **19.2 分**；最差的用户 12.0 F1，仍比最差的手工标注模型高 0.3 分。摘要中总结为建模速度 **2.8×**、预测性能平均提升 **45.5%**。

## 方法

**三阶段架构**（Figure 2）：

1. **写 labeling function**：LF 是黑箱函数 $\lambda: \mathcal{X} \to \mathcal{Y} \cup \{\emptyset\}$，$\emptyset$ 表示弃权。输入是 **Candidate** 对象——由 **context hierarchy**（Document → Sentence → Span → Entity，经 SQLAlchemy ORM 暴露）中的 Context 元组构成。提供两个抽象层级：任意 Python 函数，与声明式算子（pattern-based、distant supervision、weak classifier、LF generator）。LF generator 可用一行代码从一个结构化知识库生成数百个 LF（如按 CTD 的不同子集分别建模）。

2. **生成式模型去噪**：$m$ 个数据点 × $n$ 个 LF 得 label matrix $\Lambda \in (\mathcal{Y} \cup \{\emptyset\})^{m \times n}$，真标签 $Y$ 作为**隐变量**。因子图三类因子：

   $$\phi^{\mathrm{Lab}}_{i,j} = \mathbb{1}\{\Lambda_{i,j} \neq \emptyset\},\quad \phi^{\mathrm{Acc}}_{i,j} = \mathbb{1}\{\Lambda_{i,j} = y_i\},\quad \phi^{\mathrm{Corr}}_{i,j,k} = \mathbb{1}\{\Lambda_{i,j} = \Lambda_{i,k}\},\ (j,k) \in C$$

   分别刻画**标注倾向（labeling propensity）**、**准确率**、**成对相关性**。模型 $p_w(\Lambda, Y) = Z_w^{-1}\exp(\sum_i w^\top \phi_i(\Lambda, Y))$，通过最小化**观测 label matrix 上的负边缘对数似然** $\hat{w} = \arg\min -\log\sum_Y p_w(\Lambda, Y)$ 学习——注意这里**完全不用真标签 $Y$**。优化方式为 SGD 与 Gibbs 采样交替（类似 contrastive divergence），实现用 NUMBA 版 Gibbs 采样器 Numbskull。输出概率训练标签 $\tilde{Y} = p_{\hat w}(Y|\Lambda)$，$\tilde{y}_i \in [0,1]$。

3. **训练判别模型**：用 noise-aware 的损失期望

   $$\hat\theta = \arg\min_\theta \sum_{i=1}^m \mathbb{E}_{y \sim \tilde{Y}}[l(h_\theta(x_i), y)]$$

   实验用 bidirectional LSTM（文本）与 ImageNet 预训练的 50 层 ResNet（医学图像）。理论上（data programming 原论文）判别模型的泛化误差随**未标注数据量**增加而下降，速率与传统监督学习随人工标注量下降的渐近速率相同。

**Modeling Strategy Optimizer**（Algorithm 1）：若 $\tilde{A}^*(\Lambda) < \gamma$ 返回 MV；否则以分辨率 $\eta$ 扫描 $\epsilon$，对每个 $\epsilon$ 跑 LearnStructure 得相关集 $C$，最后按 elbow point 选 $\epsilon$ 并返回 $\mathrm{GM}_\epsilon$。

## 局限与假设

- **没有 ground truth 但需要 dev/test 集**。论文明确假设存在一个小规模 development set 用于开发调参、以及一个 blind held-out test set 用于评估（可比训练集小几个数量级）。因此"零标注"是指训练集零标注，不是全流程零标注。
- **隐变量模型的可识别性依赖 LF 的独立/相关假设**。Example 3.1 已展示相关性建模错误会导致准确率估计完全颠倒；Snorkel 只建模**成对相关**（虽称高阶依赖处理直接），且成对相关的选择靠阈值 $\epsilon$，$\epsilon$ 选择本身是性能/算力折衷。
- **收益强依赖 label density 区间**。低密度或高密度下生成模型几乎没有优势（Proposition 1 / Theorem 1），此时该步是纯开销。
- 论文主体聚焦二分类 $\mathcal{Y} = \{-1, 1\}$（实验含一个多分类应用）。
- 与 truth discovery / data fusion 的关键区别在于：这里的 LF 是**用户提供的、可以对任意数据点弃权**的信号源，这一点必须显式建模（labeling propensity 因子）。
- 结构学习的 pseudolikelihood 估计器不做采样近似，代价是需要选阈值；论文未给出 $\epsilon$ 的理论选择准则，elbow point 是启发式（用与邻居绝对差最大的点）。
