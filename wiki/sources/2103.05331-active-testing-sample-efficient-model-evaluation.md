## 概述

本文提出 **active testing（主动测试）** 框架：在测试标签昂贵的场景下，主动挑选最有信息量的测试点去标注，从而用远少于全量测试集的标签数量得到精确的 test loss 估计。与 active learning 不同，这里被评测的模型 $f$ 是**固定的**，目标不是训练模型而是估计评测统计量。作者指出主动选样必然引入 selection bias，并给出通过 **重要性采样（importance sampling）加权** 完全去偏的估计量，同时降低方差。

**论文信息**: ICML 2021（Proceedings of the 38th ICML, PMLR 139）, 2021, arXiv:2103.05331

## 关键发现

1. **naive baseline 是均匀采样**：在预算 $M$ 下均匀抽取测试子集算经验风险 $\hat{R}_{\mathrm{iid}}$，它无偏但**方差很大**——在 $M \ll N$ 的典型情形下，单次估出的 test loss 可能与全量 $\hat{R}$ 相差很远，尽管期望相等。

2. **主动选样必须配合去偏权重，否则结论会系统性偏错**。论文用 Farquhar et al. (2021) 的 $\hat{R}_{\mathrm{LURE}}$ 估计量：必须**随机地**从一个**已知概率的 acquisition distribution** $q(i_m)$ 中抽样，再对每个被标注点乘以权重 $v_m$ 校正。Fig. 8(a) 的实证结果：直接按 predictive entropy 取点却用未加权的 $\hat{R}_{\mathrm{iid}}$，估计结果是**有偏且高方差的，并且明显高估模型误差**（因为模型最不确定的点通常也更难）。

3. **acquisition 的理论最优解是"按期望损失采样"**：$q^*(i_m) \propto \mathbb{E}_{p(y|\mathbf{x}_{i_m})}[\mathcal{L}(f(\mathbf{x}_{i_m}), y)]$。它不可得（需要真标签分布），因此用一个 **surrogate（代理模型）** $\pi$ 来近似期望损失。Fig. 8(a) 通过"向 oracle 询问真损失"验证了这一假设：按真损失采样确实给出精确的单样本估计。

4. **surrogate 的选择比"更准"更重要的是"更不一样"**。论文总结四条策略：uncertainty（同时刻画 epistemic 与 aleatoric 不确定性且需校准）、fidelity（测试时可用更强的模型）、diversity（换模型族以去相关误差）、extra data（在 $\mathcal{D}_{\mathrm{train}} \cup \mathcal{D}_{\mathrm{test}}^{\mathrm{observed}}$ 上重训 surrogate）。实验中 random forest 作为 ResNet-18 的 surrogate 表现最好，尽管它本身精度更低；Fig. 7 显示 diversity 的增益大于 fidelity（5 个 ResNet-18 的 ensemble 优于单个 ResNet-50）。

5. **active testing 的 acquisition function 与 active learning 的不能直接复用**。active learning 常用的 mutual information / BALD 刻意**回避** aleatoric uncertainty（不可约的标签噪声），但对评测而言所有不确定性都影响估计量方差，因此必须纳入。Fig. 8(b) 实测 mutual information 在 active testing 上劣于 predictive entropy。作者还指出：在训练阶段有偏的 loss estimator 有时反而有益（可部分抵消训练损失的偏差），但测试阶段必须把偏差压到最小。

6. **常用 loss 的 acquisition 都有闭式形式**。回归的平方误差经 bias-variance 分解得 $q(i_m) \propto (f(\mathbf{x}_{i_m}) - \mathbb{E}[y])^2 + \mathbb{V}[y]$（模型与 surrogate 预测之差 + surrogate 的预测方差）；分类的 cross-entropy 得 $q(i_m) \propto -\sum_y \pi(y|\mathbf{x}_{i_m}) \log f(\mathbf{x}_{i_m})_y$，即 surrogate 边缘预测分布与被测模型之间的交叉熵；accuracy 得 $q(i_m) \propto 1 - \pi(y = y^*(\mathbf{x}_{i_m})|\mathbf{x}_{i_m})$。

## 方法

**设定**：给定固定模型 $f$ 与规模 $N$ 的测试集，目标是估计全量 test loss $\hat{R} = \frac{1}{N}\sum \mathcal{L}(f(\mathbf{x}_{i_n}), y_{i_n})$，但只能标注其中 $M$ 个点。标注按顺序进行（索引 $m$），每步获得的标签可用于选择后续点。

**去偏估计量**（核心）：

$$\hat{R}_{\mathrm{LURE}} = \frac{1}{M}\sum_{m=1}^{M} v_m \mathcal{L}(f(\mathbf{x}_{i_m}), y_{i_m}), \quad v_m = 1 + \frac{N-M}{N-m}\left(\frac{1}{(N-m+1)q(i_m)} - 1\right)$$

**关键前提**：$i_m$ 必须是从 acquisition 分布 $q(i_m)$ **随机抽样**得到，且该概率 $q(i_m)$ **已知**（这是权重 $v_m$ 可计算的唯一依据）。论文强调 $q$ 可以任意依赖已获得的测试标签、训练数据和被测模型（$q(i_m) \equiv q(i_m; i_{1:m-1}, \mathcal{D}_{\mathrm{test}}, \mathcal{D}_{\mathrm{train}})$）而不破坏无偏性。

**surrogate 近似**：用 surrogate 的后验预测近似期望损失，$q(i_m) \propto \mathbb{E}_{\pi(\theta)\pi(y|\mathbf{x}_{i_m},\theta)}[\mathcal{L}(f(\mathbf{x}_{i_m}), y)]$。算法流程（Algorithm 1）：训练 surrogate → 每步 $i_m \sim q$、观测 $y_{i_m}$、计算 loss 与 $v_m$ → 周期性用新标签更新 surrogate → 返回 $\hat{R}_{\mathrm{LURE}}$。

**工程细节**：为所有点设定一个**最小 proposal 概率**下限，使得即使 $q$ 校准很差，重要性权重仍有界（避免权重爆炸）。

## 重要数据

| 实验设定 | 结果 |
|---------|------|
| 合成回归（GP/GP） | 仅获取 5 个测试点时，active testing 的标准差已低至 i.i.d. 采样第 40 步（接近全量测试集）的水平 |
| Radial BNN on MNIST | 重训的 BNN surrogate 优于直接用原模型的 predictive entropy；random forest surrogate 未超过原模型 |
| ResNet-18 on Fashion-MNIST（训练集仅 250 点） | 直接用原模型 predictive entropy **差于** i.i.d. 采样；random forest surrogate 表现最好 |
| ResNet-18 on CIFAR-10 / Fashion-MNIST | 相对标注成本（relative labeling cost）约为 0.25 量级，即样本效率约 4 倍 |
| WideResNet on CIFAR-100 | 样本效率增益约 2 倍（任务越复杂，损失越难预测） |
| 无去偏权重（$\hat{R}_{\mathrm{iid}}$ + 熵采样） | 估计有偏、方差高，且明显高估模型误差 |

实验规模：Fig. 4 的中位平方误差分别基于 1085 次（Radial BNN/MNIST）与 872 次（ResNet-18/Fashion-MNIST）运行；Fig. 3 的合成实验为 5000 / 2500 次运行；CIFAR 实验训练集规模 50,000。代码：github.com/jlko/active-testing。

## 局限与假设

- **必须能算出采样概率**。整套无偏性建立在"随机化 + 已知 $q(i_m)$"之上。任何确定性的 top-$k$ 挑选、人工筛选、或概率未记录的采样都无法用 $\hat{R}_{\mathrm{LURE}}$ 去偏——这是把该方法搬到 LLM 评测集抽样时最容易踩的坑。
- **无偏但方差取决于 surrogate 质量**。surrogate 差只损失效率不损失无偏性（Fig. 4 中所有方法都是无偏的），但 Fig. 5 显示 predictive entropy 会把某些点的真实损失低估几个数量级（高置信度错误），使这些最关键的点几乎不被采到。
- **pool-based 且不放回**：权重 $v_m$ 的形式依赖有限池规模 $N$ 与不放回抽样；论文批评 Sawade et al. (2010) 的有放回采样在 pool-based 设定下次优。
- 论文明确"不推荐"仅用原模型自身作 surrogate，仅在有充分理由信任原模型不确定性时作为最后手段。
- 实验限于图像分类与小规模回归任务（MNIST/Fashion-MNIST/CIFAR-10/CIFAR-100 + 合成数据），未涉及生成式模型或 LLM 评测；论文以 test loss / accuracy 这类可分解为逐样本 loss 的统计量为目标，非逐样本可分解的指标未讨论。
- 若 surrogate 需在每次采样后重训，计算成本可能与标注成本相当；论文建议当重训成本相对标注成本不可忽略时可不重训，但会牺牲样本效率。
