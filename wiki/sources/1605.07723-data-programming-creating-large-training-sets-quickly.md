## 概述

Ratner 等人提出 data programming：用户不再手工标注样本，而是编写一批 **labeling function**（标注函数）$\lambda_i:\mathcal{X}\mapsto\{-1,0,1\}$——每个函数对数据的某个子集给出可能有噪声、可能相互冲突的标签；系统把这批标注函数的输出建成一个生成模型，自动学出各函数的准确率与它们之间的相关结构，从而对生成的训练集「去噪」，再用一个 **noise-aware** 的损失函数训练下游判别模型。论文在理论上证明，在一定条件下只需 $O(1)$ 个标注函数与 $\tilde{O}(\varepsilon^{-2})$ 个**无标注**样本，就能达到与有监督学习相同的渐近 scaling；实验上在 2014 TAC-KBP Slot Filling 等三个关系抽取任务上平均提升 2.34 个 F1 点。这篇论文是 Snorkel（当时称 DDLite）的理论基础，也是「有向标注函数依赖」在弱监督侧的代表性建模。

**论文信息**: NeurIPS/NIPS 2016（PDF 为 arXiv:1605.07723v3, 2017-01-08；正文日期 2016-05-26）; 作者 Alexander Ratner, Christopher De Sa, Sen Wu, Daniel Selsam, Christopher Ré（Stanford University）。

## 关键发现

1. **独立情形的生成模型只有两组参数：覆盖率与准确率。** 每个标注函数 $\lambda_i$ 以概率 $\beta_i$ 决定是否给某对象打标签，打了标签时以概率 $\alpha_i$ 打对；类先验取 0.5。分布为 $\mu_{\alpha,\beta}(\Lambda,Y)=\frac{1}{2}\prod_{i=1}^{m}\left(\beta_i\alpha_i\mathbf{1}_{\{\Lambda_i=Y\}}+\beta_i(1-\alpha_i)\mathbf{1}_{\{\Lambda_i=-Y\}}+(1-\beta_i)\mathbf{1}_{\{\Lambda_i=0\}}\right)$（式 1）。参数用极大似然（式 2）拟合，实现上用 SGD。论文指出这个模型在独立情形下**等价于众包的基本模型**（Sec. 3 明言 "can be considered equivalent to the crowdsourcing setting in the independent case"），差别在于众包关注「大量标注者各标一小部分」，而 data programming 关注「少量标注函数各覆盖大部分数据集」。

2. **四类标注函数依赖：similar / fixing / reinforcing / exclusive。** 用户可提供一张 **标注函数依赖图** $G\subset\mathcal{D}\times\{1,\dots,m\}\times\{1,\dots,m\}$，边带依赖类型。论文给出的判别标准是行为模式：若 $\lambda_2$ 通常**只在** $\lambda_1$ 也打标签时才打标签、且二者**不一致**、而 $\lambda_2$ 是对的，这叫 **fixing dependency**（$\lambda_2$ 修正 $\lambda_1$ 的错误）；若在同样的「只在 $\lambda_1$ 打标签时才打标签」结构下二者通常**一致**，则是 **reinforcing dependency**（$\lambda_2$ 强化 $\lambda_1$）。注意 fixing/reinforcing 是**有向**依赖。

3. **依赖通过因子图的额外因子编码。** 有依赖时模型从朴素贝叶斯网改为因子图 $\mu_\theta(\Lambda,Y)=Z_\theta^{-1}\exp(\theta^{T}h(\Lambda,Y))$。基础因子为 $h_0=Y$、$h_i=\Lambda_i Y$、$h_{m+i}=\Lambda_i$、$h_{2m+i}=\Lambda_i^2 Y$、$h_{3m+i}=\Lambda_i^2$。再按依赖图加因子：near-duplicate（similar）加单个 $h_t=\mathbf{1}\{\Lambda_i=\Lambda_j\}$，提高标签一致的先验概率；**fixing** 加两个因子 $h_{t+1}=-\mathbf{1}\{\Lambda_i=0\wedge\Lambda_j\neq 0\}$ 与 $h_{t+2}=\mathbf{1}\{\Lambda_i=-Y\wedge\Lambda_j=Y\}$，编码「$\lambda_j$ 只在 $\lambda_i$ 打标签时打标签，且修正 $\lambda_i$ 的错误」；**reinforcing** 的因子形式相同，只把第二个换成 $h_{t+1}=\mathbf{1}\{\Lambda_i=Y\wedge\Lambda_j=Y\}$；**exclusive** 用单个 $h_t=-\mathbf{1}\{\Lambda_i\neq 0\wedge\Lambda_j\neq 0\}$。依赖情形下用 SGD + Gibbs 采样学 $\hat\theta$。

4. **两个理论保证：样本复杂度与有监督同阶。** 定理 1（独立情形，在式 4/5/6 条件下、$m\geq 2000$）：若 $|S|\geq \frac{356}{\varepsilon^{2}}\log\frac{m}{3\varepsilon}$，则 $\mathbf{E}\|\hat\alpha-\alpha^{*}\|^{2}\leq m\varepsilon^{2}$、$\mathbf{E}\|\hat\beta-\beta^{*}\|^{2}\leq m\varepsilon^{2}$、$\mathbf{E}[l(\hat w)-\min l(w)]\leq \chi+\frac{\varepsilon}{27\rho}$。定理 2（含依赖情形）：$|S|\geq \frac{2}{c^{2}\varepsilon^{2}}\log\frac{2\|\theta_0-\theta^{*}\|^{2}}{\varepsilon}$ 时给出同型界。结论是只需 $\tilde{O}(\varepsilon^{-2})$ 个**无标注**样本，与有监督方法同阶——「更丰富的依赖结构付出的是计算代价，而不是统计效率代价」。与众包设定的对比很关键：众包里标注者数 $m\to\infty$，而这里 $m$ 是常数、数据集在增长。

5. **实证：三个关系抽取任务平均 +2.34 F1，含一个本可夺冠的成绩。** 与 if-then-return（ITR，把标注函数排成 if-then 序列取第一个命中的标签，即典型远监督做法）基线对比，data programming 在 KBP(News)/Genomics/Pharmacogenomics 三个应用上一致提升，平均 2.34 F1 点；在 2014 TAC-KBP Slot Filling 上该分数本可拿到该届竞赛第一。

6. **与自动生成特征叠加同样有效。** 用 LSTM 自动学特征替代手工特征时，data programming 相对 ITR 基线在 KBP(News) 上提升 precision 9.79 点、F1 3.12 点；相对一个 state-of-the-art LSTM 方法（Verga et al.）提升 5.98 F1 点，可进入该竞赛第二名。论文指出常规认知是深度模型容易过拟合弱监督规则的偏差，而生成模型去噪能缓解这一点。

7. **可用性研究：8 小时内非 ML 专家做出接近有监督基线的抽取器。** 一场面向生物信息学研究者的 hackathon 上，参与者用开源框架 Snorkel（前称 DDLite）做疾病标注任务，无标注训练集、不做特征工程，全部精力放在迭代写标注函数与搭建候选集上；不到 8 小时做出的模型 F1 落在有监督基线的 10 点以内，差距主要来自候选抽取阶段的 recall 问题。

## 方法

**问题设定**：二分类，分布 $\pi$ 定义在 $\mathcal{X}\times\{-1,1\}$ 上，目标是最小化线性模型下的 logistic loss $l(w)=\mathbf{E}_{(x,y)\sim\pi}[\log(1+\exp(-w^{T}f(x)y))]$，其中 $\|f(x)\|\leq 1$。用户提供 $m$ 个标注函数，向量化为 $\lambda:\mathcal{X}\mapsto\{-1,0,1\}^{m}$（0 表示弃权）。标注函数可以基于外部知识库、库/本体、启发式模式，或它们的混合。论文强调标注函数**严格比人工标注更一般**：一条人工标注总可以直接编码成一个标注函数。

**潜变量**：真实类标 $Y\in\{-1,1\}$，从不被观测；观测量只有标注函数输出 $\Lambda\in\{-1,0,1\}^{m}$。

**两步流程**：
1. 用式 (2) 的极大似然（对 $Y$ 边缘化）估计生成模型参数 $(\hat\alpha,\hat\beta)$ 或 $\hat\theta$；
2. 用 **noise-aware empirical risk minimizer**（式 3）训练判别模型：$\hat w=\arg\min_w \frac{1}{|S|}\sum_{x\in S}\mathbf{E}_{(\Lambda,Y)\sim\mu_{\hat\alpha,\hat\beta}}\left[\log(1+e^{-w^{T}f(x)Y})\mid \Lambda=\lambda(x)\right]+\rho\|w\|^{2}$，即对 $Y$ 的后验取期望而非硬标签。

**关键假设**：
- **式 (4)/(7) 模型可实现性**：真实分布必须能被参数族准确表示，即存在 $\alpha^{*},\beta^{*}$（或 $\theta^{*}\in\Theta$）使 $\mathbf{P}_{(x,y)\sim\pi^{*}}(\lambda(x)=\Lambda, y=Y)=\mu_{\alpha^{*},\beta^{*}}(\Lambda,Y)$。
- **式 (5) 条件独立性**：给定标注函数输出后，类标与特征独立，$(x,y)\sim\pi^{*}\Rightarrow y\perp f(x)\mid \lambda(x)$。论文的解读是「标注函数可以任意依赖特征，但必须提供足以准确识别类别的信息」。
- **式 (6) 优化器有界泛化风险**（参数 $\chi$）；参数范围约束（论文取 $0.3\leq\beta_i\leq 0.5$、$0.8\leq\alpha_i\leq 0.9$，称与实践经验大致相符：用户倾向写高准确率、高覆盖的标注函数）。
- 依赖情形额外要求（式 8/9）：存在方差满足 $\mathbf{Cov}(\hat\theta(T))\leq(2c|T|)^{-1}I$ 的无偏估计量；以及对任意两个可行模型，$\mathbf{E}[\mathbf{Var}(Y_2\mid\Lambda_1=\Lambda_2)]\leq cM^{-1}$，即「即使猜错了 $\theta$，对 $Y$ 的猜测仍相当确定」。

## 局限与假设

- **理论保证依赖强假设**：模型可实现性（式 4/7）要求真实的 $(\Lambda,Y)$ 联合分布正好落在参数族里；一旦标注函数间存在未被依赖图覆盖的相关，准确率估计会有偏。定理 1 还要求 $m\geq 2000$（论文说明这只是为了让定理陈述简洁，一般 $m$ 的完整版本在附录），而实验里的 $m$ 是 7–146，与定理的简化条件不在同一区间。
- **依赖结构由用户给定**：依赖图 $G$ 及边的类型是**用户输入**，论文只学依赖强度、不发现结构（结构学习是后续工作，如 Snorkel 系列与 Language Models in the Loop 一线）。若用户判断错了依赖类型（把 fixing 当 reinforcing），因子形式就错了。
- **依赖情形下要 Gibbs 采样**：论文明说更丰富的依赖结构付出的是计算代价；条件独立情形有闭式因子结构而依赖情形需要采样。
- **式 (5) 的条件独立仍需成立**：要求给定标注函数输出后类标与特征独立；这不是「标注函数之间条件独立」，但也排除了「特征里含有标注函数没捕捉到的、与类标直接相关的信息」这一常见现实。
- **二分类、线性模型的分析范围**：全部理论围绕二分类 + logistic loss + 有界特征展开；多分类、结构化预测、图像等在结论部分被列为未来工作。
- **有向依赖不等于识别力**：论文的 fixing/reinforcing 是有向依赖的建模范例，但其识别力来自模型可实现性 + 参数范围约束 + 大量无标注数据，而非「有向性」本身对可观测分布的额外限制——把有向依赖直接当作可识别性杠杆时需格外小心。
- **实验域集中在关系抽取**：三个主任务都是关系 mention 抽取，另有一个疾病 mention 抽取；跨域普适性未在本文验证。
