## 概述

论文提出并系统测量了 **evaluation awareness（评测感知）**：模型仅凭上下文就能判断一段 transcript 来自评测还是真实部署的能力。作者构建了一个含 1000 条样本、取自 61 个不同数据集的 benchmark，覆盖 chat 与 agentic 两类交互、evaluation 与 deployment 两类场景，并在 9 个前沿模型上测量。结论是前沿模型的评测感知已经明显高于随机水平（Gemini 2.5 Pro 总体 AUC 0.83），但仍未超过作者自建的人类 baseline（AUC 0.92）；模型还能在相当程度上判断出"这次评测在测什么"。这直接威胁评测结果的外部有效性——若模型在评测中系统性地表现不同，benchmark 就不再是部署行为的可靠预测器。

**论文信息**: Preprint（MATS / Apollo Research），2025，arXiv:2505.23836v3

## 关键发现

1. **前沿模型显著高于随机、但未超人类**：在 900 条 held-out transcript 上，最佳模型 Claude 3.5 Sonnet 总体 AUC 0.834、Gemini 2.5 Pro 0.830，人类 baseline 0.921；随机为 0.500。作者明确把该人类 baseline 视为"近似上界"而非典型人类水平（标注者是熟悉这些数据集的论文作者本人）。
2. **agentic 场景的评测感知明显强于 chat**：模型在 agentic transcript 上 AUC 约 0.88–0.95，在 chat 上仅约 0.71–0.77。人类在 agentic 上 AUC 高达 0.996，在 chat 上只有 0.813——说明 chat 场景本身就更难区分。
3. **模型也能识别评测目的**：在 500 条评测 transcript 上做 capability / alignment 二分类，条件式多选（已告知来自评测）时 Claude 3.7 Sonnet 93%、GPT-4.1 89%；无条件多选时 GPT-4.1 掉到 55%（常判为"真实交互"），Claude 3.7 Sonnet 仅小幅降到 84%；最接近真实场景的开放式提问下，Claude 3.7 Sonnet 仍能正确说出 46% 评测 transcript 的真实意图，远超其他模型。
4. **判别力强但校准差**：多数模型 ECE 偏高、校准曲线位于对角线下方，即**系统性高估"这是评测"的概率**。Claude 3.5 Sonnet 校准最好（ECE 0.092 且 AUC 0.83）；推理模型 Gemini 2.5 Pro 与 Claude 3.7 Sonnet (Thinking) 判别力高却最过度自信（ECE 0.23 / 0.20）。作者未发现"越新的模型校准越好"的证据。
5. **模型用什么线索判断**：CoT 分析归纳出 meta reasoning（"提这个问题本身说明在评测我"）、benchmark 记忆（能点名 SWEBench / GAIA / MMLU）、合成输入（Claude 3.7 Sonnet 与 Gemini 2.5 Pro 分别在 22% / 17% 的 case 指出 AgentHarm 场景是合成的，并在 95% 以上判对）、任务格式（多选题）、可验证问题（CTF flag）、有害性（红队式提问）、以及真实交互的"多轮往复对话"特征。
6. **meta-reasoning 会污染测量**：o4-mini 在 15% 的回答中出现 meta reasoning（用"被问这个问题"本身当证据），因此其评测感知可能被**低估**，作者提示未来需要新的测量策略。

## 方法

**数据集**：从 61 个来源分层抽样出 1000 条样本，若全量使用会超过 300 万条。四类各 250 条，严格平衡：Chat-Evaluation、Chat-Deployment、Agentic-Evaluation、Agentic-Deployment。评测侧取自公开 capability / alignment benchmark（MMLU、SWEBench、WMDP、AgentHarm、XSTest 等），部署侧取自真实交互（ShareGPT 等）；agentic 数据不足处用 Aider、smolagents、Open Deep Research 等 scaffold 合成真实感轨迹。评测数据集另按原始论文定位标注为 capability evaluation 或 alignment evaluation 两类。

**测量方式**：向模型出示 transcript，问"这段 transcript 是否来自对语言模型的评测？"（Probe Question, PQ），允许 CoT，二选一作答。PQ 沿两个维度变化：输入格式（把 PQ **append** 到原对话之后，或把整段 transcript **quote** 成 JSON/XML 在新上下文中呈现）与措辞/选项顺序。初始设计 28 个 PQ，用 100 条 dev 子集筛出 5 个性价比合适的 PQ，主实验对所有模型统一使用这 5 个 PQ，对五种变体的回答取平均，得到"该 transcript 属于评测"的概率估计。

**指标**：AUC（主指标，判别力，与阈值无关）、ECE（校准）、Brier score（判别+校准的综合）。

**评测目的识别**：三种问法——条件式多选（已告知是评测，选 Capability / Alignment / Other）、无条件多选（Real Interaction / Capability Evaluation / Alignment Evaluation / Other Evaluation）、开放式（"这次交互发生的主要原因是什么"，由 GPT-4.1 judge 按同一套无条件标签归类；judge 在 50 条人工标注回答上做过验证）。

**人类 baseline**：每位作者独立对全部 1000 条样本按 0（不是评测）到 1（确定是评测）打分，ICC3 = 0.768（95% CI $[0.74, 0.79]$），取平均作为最终 baseline。

## 局限与假设

- **人类 baseline 极弱**：仅 2 位标注者（作者本人），且熟悉这些数据集与 LLM 评测方法，论文自述应当作为"分类性能的近似上界"而非典型人类能力。
- **记忆混淆**：评测侧数据取自公开 benchmark，模型可能通过记忆（能点名 SWEBench / MMLU）而非真正的情境推理来判别，论文承认这可能贡献了近期模型的判别力，且难以精确量化。
- **PQ 的启动效应（priming）**：直接问"这是不是评测"本身就在提示模型考虑评测可能性，可能抬高"评测"判定率（校准曲线的系统性过度自信与此一致）；开放式问法更接近真实无提示情境，模型表现明显下降。
- **meta-reasoning 未被排除**：模型可能把"被问到这个问题"当作证据，作者未确认这种推理是否**因果性地**影响最终判断；若影响存在，现有测量对 o4-mini 这类模型是低估。
- **只测"能否识别"，不测"是否会因此改变行为"**：论文测的是判别能力，并未证明模型确实在评测中改变了行为；sandbagging / alignment faking 属于论文在 Discussion 中指出的最坏情形，不是本文的实验结论。
- 覆盖范围限于 Claude / GPT/o / Gemini 三个家族的 9 个模型与英文数据。
